# API Reference

This project is built with FastAPI, and the runtime API schema is generated automatically from the application.

## Local API preview

Run the server locally:

```bash
uv run fastapi dev pfun_cma_model/app.py --port 8001
```

Then open one of these local API viewers:

- `http://127.0.0.1:8001/docs` — Swagger UI
- `http://127.0.0.1:8001/redoc` — ReDoc UI
- `http://127.0.0.1:8001/openapi.json` — raw OpenAPI schema

## API reference guidance

The API schema is generated by FastAPI from the application source.
If you want a static API reference artifact, fetch the OpenAPI schema from the running app:

```bash
curl http://127.0.0.1:8001/openapi.json -o openapi.json
```

Then use your preferred OpenAPI tooling to produce reference docs from that schema.

## Key API endpoints

- `GET /openapi.json` — OpenAPI schema
- `GET /docs` — Swagger UI
- `GET /redoc` — ReDoc UI

## Notes

Because the application exposes its API schema dynamically, the most accurate API documentation is generated from the live FastAPI app.
Keep the app sources in `pfun_cma_model/` in sync with this documentation.
